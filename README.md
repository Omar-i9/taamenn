# تأمين 2026 — V5 AI Assistant Hub

إصدار V5 يضيف صفحة المساعد الذكي كصفحة مستقلة تعمل محليًا من بيانات الموقع، مع تثبيت إعادة بناء الرادار التكتيكي بمفاتيح تخزين جديدة ومنطق ربط واحد.

- إضافة صفحة `ai` داخل `index.html` باسم المساعد الذكي / غرفة التحليل الذكي.
- إضافة زر AI في شريط الكمبيوتر وقائمة الجوال وزر عائم مستقل لا يضع أي API key داخل الواجهة.
- نقل الطقس والصلاة، الإصابات، القبلة، دليل الاستخدام، وعن المنصة إلى قائمة `المزيد` في شريط الكمبيوتر.
- إضافة `js/modules/ai-assistant.js` لبناء معرفة محلية من بيانات الموقع والرد بدون Backend.
- إضافة `js/modules/api-client.js` مع `AI_ENDPOINT` فارغ وجاهز لاحقًا للربط الآمن عبر Backend.
- تثبيت الرادار على مفاتيح تخزين جديدة:
  - `taamen.radar.v5.players`
  - `taamen.radar.v5.activeTactic`
- قراءة مفاتيح الرادار القديمة فقط بعد validation، ثم migration آمن أو reset للبيانات الافتراضية.
- تحديث `sw.js` إلى كاش V5.1 وإضافة ملفات AI الموجودة فعليًا.
- إضافة ملاحظات الإصدار في `docs/V5_RADAR_REBUILD_NOTES.md`.
- إضافة دليل المساعد في `docs/AI_ASSISTANT_GUIDE.md`.

## ملاحظة أمان AI

المساعد الحالي Frontend-only ويعمل بفallback محلي. لا يوجد اتصال مباشر مع OpenAI من المتصفح، ولا يوجد API key داخل `HTML` أو `JS` أو `localStorage`.

عند الحاجة لذكاء حقيقي لاحقًا، يجب تشغيل Backend خارجي آمن يقرأ متغيرات البيئة سرًا، ثم تضبط الواجهة `AI_ENDPOINT` فقط.

## تشغيل سريع

افتح `index.html` مباشرة أو انشره على GitHub Pages. بعد الرفع، نفذ تحديثًا قاسيًا للمتصفح:

```txt
Ctrl + Shift + R
```

- سجل مخفي لكل إصابة.

- تعطيل الرجوع التلقائي لآخر صفحة: الموقع يبدأ دائمًا من الرئيسية إلا إذا دخل المستخدم من رابط هاش مباشر.

## ملاحظة عن القبلة

القبلة تُحسب محليًا من موقع الجهاز ومعادلة اتجاه الكعبة. البوصلة الحية تحتاج مستشعر بوصلة في الجهاز. لذلك اللابتوب غالبًا سيعرض الدرجة فقط بدون سهم حي.

## ملاحظة عن لقطة الشاشة

المتصفح لا يسمح للموقع بمعرفة أن المستخدم أخذ Screenshot من أزرار النظام أو قراءة الصورة الملتقطة. لذلك تم إضافة زر عائم داخل الموقع يلتقط الصفحة الحالية ويشاركها أو ينزلها حسب دعم الجهاز.
