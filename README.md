# تأمين 2026 Legacy Edition — V3 Final

نسخة كاملة منظمة مبنية على التقسيم الجديد:

- شريط تنقل مختصر للكمبيوتر.
- زر **المزيد** للصفحات الثانوية وروابط المبرمج.
- ثيمين فقط: ليل ملكي وغروب غامق. لا يوجد ثيم أبيض مزعج.
- انتقال تدريجي لألوان الخلفية والبطاقات والأزرار عند تغيير الثيم.
- أرشيف كامل للمباريات القديمة والجديدة والودية.
- مركز مباراة قادمة مع عداد ساخن عند اقتراب الموعد خلال 24 ساعة.
- رادار تكتيكي واسع للجوال والكمبيوتر.
- مواقيت صلاة وطقس حسب الخليل أو القدس.
- صفحة دليل استخدام تشرح كل صفحة وكل زر مهم.

## طريقة التشغيل

الأفضل تشغيله عبر سيرفر محلي أو رفعه على GitHub Pages لأن الموقع يستخدم ES Modules.

### تشغيل محلي سريع

```bash
python -m http.server 8000
```

ثم افتح:

```txt
http://localhost:8000
```

## تعديل المباريات

افتح:

```txt
data/site-data.js
```

### إضافة مباراة للأرشيف

أضف داخل `matchArchive`:

```js
{
  id: 'M-204',
  type: 'strong', // normal | strong | friendly
  team1: 'عمر',
  team2: 'كريم',
  score1: 7,
  score2: 6,
  status: 'انتهت',
  dateLabel: 'الجمعة 22 مايو',
  dateKey: 20260522,
  story: 'وصف قصير للمباراة'
}
```

### إضافة مباراة قادمة

أضف داخل `upcomingMatches`:

```js
{
  id: 'UP-003',
  title: 'مواجهة الجمعة',
  team1: 'تأمين',
  team2: 'التحدي',
  location: 'ملعب سيدات الخليل',
  weekday: 5,
  hour: 19,
  minute: 0,
  durationMinutes: 60,
  note: 'أي ملاحظة تظهر بالموقع'
}
```

## أهم الملفات

| الملف | وظيفته |
|---|---|
| `index.html` | هيكل الصفحات وشريط التنقل |
| `css/12-v3-final.css` | تعديلات النسخة النهائية: التنقل، الثيم، الخطوط، الجوال |
| `data/site-data.js` | المباريات، اللاعبين، التكتيكات، الشروحات |
| `js/modules/router.js` | التنقل بين الصفحات وزر المزيد |
| `js/modules/matches.js` | مركز المباراة والأرشيف |
| `js/modules/tactical.js` | الرادار التكتيكي |
| `js/modules/weather.js` | الطقس وجاهزية اللعب |
| `js/modules/prayer.js` | مواقيت الصلاة |
