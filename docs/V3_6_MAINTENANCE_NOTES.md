# تأمين 2026 — V3.6 Maintenance Pro Fix

هذا التحديث مخصص لإصلاح المشاكل العملية التي ظهرت بعد تحديث الإصابات والرادار.

## ما الذي تم إصلاحه؟

- إصلاح أزرار الصفحة الرئيسية: زر **ابدأ من المباراة القادمة** وزر **جهز التشكيلة**.
- تقوية نظام التنقل حتى تعمل كل العناصر التي تحمل `data-route` حتى لو كان فوقها تأثير بصري أو طبقة CSS.
- إصلاح نافذة تعديل اللاعب داخل الرادار:
  - زر الحفظ صار زرًا مباشرًا بدل الاعتماد على سلوك `dialog` الافتراضي.
  - زر الإغلاق صار زرًا مباشرًا.
  - زر المسح بقي شغال كما كان.
  - اختيار دور اللاعب والتعليمات يحفظ فعليًا بعد الضغط على حفظ.
- تحسين اللمس والسحب داخل الملعب التفاعلي.
- إعادة بناء فتح خطة العلاج وسجل الحالة بدون استخدام `details` الافتراضي، حتى لا يقفز المستخدم لأول الصفحة.
- تحويل سجل الإصابات السابقة إلى شريط طويل قابل للفتح، مشابه لفكرة مجموعات الملفات في ويندوز.
- إخفاء أي ملاحظات تعديل بيانات من واجهة المستخدم العادي.
- إضافة ملف شرح شامل لتعديل بيانات الموقع يدويًا.

## منطق الإصابات الجديد

الحالات تنقسم تلقائيًا إلى قسمين:

1. **إصابات نشطة**: تظهر في الصفحة الرئيسية وفي صفحة الإصابات.
2. **سجل سابق / متعافين**: يظهر داخل شريط طويل مغلق، ويفتحه المستخدم عند الحاجة.

تنتقل الحالة إلى السجل السابق إذا:

- كانت `severity: 'healed'`
- أو كانت `severity: 'recovery'`
- أو كان `status` يحتوي على كلمة `تعافى`
- أو مر تاريخ `recoveryDate`
- أو مر تاريخ `expectedReturn`

يمكن منع الأرشفة التلقائية لأي حالة بوضع:

```js
autoArchive: false
```

داخل بيانات الحالة.
