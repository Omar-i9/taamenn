# Taamen 2026 - V5 Radar Rebuild

## ما الذي تغير؟

- عاد مسار `radar` كصفحة حقيقية داخل الموقع.
- تمت إعادة بناء `js/modules/tactical.js` من الصفر بدل الاعتماد على منطق الرادار القديم.
- تمت إضافة طبقة CSS نهائية: `css/22-radar-rebuild.css`.
- تمت إعادة أزرار الرادار إلى شريط الكمبيوتر، قائمة الجوال، الصفحة الرئيسية، ومركز المباراة.
- تم تحديث `sw.js` بإصدار كاش جديد وملفات الرادار الجديدة.

## كيف يعمل الرادار؟

الرادار يعرض ملعب 5 ضد 5 مع خمسة لاعبين لكل فريق. فريق `home` يبقى في النصف الأيسر، وفريق `away` يبقى في النصف الأيمن، إلا إذا أخذ اللاعب دور `لاعب حر`.

كل لاعب يعرض:

- الاسم.
- المركز التلقائي حسب موقعه.
- علامة الكابتن عند وجودها.
- الدور أو التعليمات عند توفرها.

## تعديل اللاعبين

اضغط مرتين على اللاعب داخل الملعب أو استخدم زر التعديل من لوحة الفريق/مفتش اللاعب. النافذة تدعم:

- تعديل الاسم.
- اختيار اسم سريع من `playerPool`.
- اختيار دور من `roleOptions`.
- اختيار تعليمات من `instructionOptions`.
- تعيين كابتن واحد فقط لكل فريق.
- إعادة اللاعب إلى بياناته الافتراضية.

## تعديل الخطط

الخطط تأتي من `tactics` داخل:

```txt
data/site-data.js
```

عند إضافة خطة جديدة، حافظ على نفس شكل البيانات:

```js
{
  id: 'custom',
  name: 'اسم الخطة',
  description: 'وصف مختصر',
  positions: {
    home: [{ x: 8, y: 50 }],
    away: [{ x: 92, y: 50 }]
  }
}
```

سيقوم الرادار بحصر الإحداثيات داخل نصف الفريق تلقائيًا.

## التخزين المحلي

المفاتيح المستخدمة:

```txt
taamen.radar.v5.players
taamen.radar.v5.activeTactic
```

إذا كانت البيانات الجديدة تالفة، يحاول الرادار قراءة المفاتيح القديمة بعد التحقق منها فقط. إذا فشلت، يرجع إلى `defaultPlayers` بأمان.

## اختبار الصفحة

اختبر:

- فتح `#radar` من شريط الكمبيوتر.
- فتح `#radar` من قائمة الجوال.
- فتح الرادار من بطاقة الرئيسية ومركز المباراة.
- سحب اللاعبين بالماوس واللمس.
- تطبيق كل خطة.
- حفظ التعديل وإغلاق النافذة وإعادة اللاعب.
- التصدير عند تحميل `html2canvas`.
- عرض الجوال عند 360px و390px و430px و768px.
