## Headline

TAAMEN 2.0 — local-first football workspace (live site, code, brand)

## Summary

TAAMEN is a football-first web app: a normal user keeps a local profile, matches, archive, and tactical board in the browser. A separate Featured Member path is a server-checked identifier for read-only historical records. Support contact is a real server form, not a frontend mail widget.

The product is functional and local-first. It is not a SaaS billing platform, not an AI product, and not a customer base.
