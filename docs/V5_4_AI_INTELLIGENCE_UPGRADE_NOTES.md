# AI Assistant Intelligence Upgrade

هذا التحديث يرفع المساعد الذكي من مساعد يقرأ بيانات الموقع فقط إلى مساعد أكثر مرونة:

- يقرأ بيانات تأمين الرسمية من `siteKnowledge`.
- يستخدم حزمة معرفة عامة محلية قابلة للتوسع بدون إرسالها كاملة إلى النموذج.
- يصنف السؤال إلى نية، مواضيع، ومستوى أمان.
- يقسم الأسئلة المركبة إلى محاور قصيرة.
- يرفض طلبات الاختراق أو تجاوز الخصوصية، ويقدم بديلا دفاعيا آمنا.
- يرجع إلى رد محلي عند فشل الاتصال بالخادم أو انتهاء المهلة.

## AI Knowledge Pack and Multi-Topic Assistant Upgrade

تمت إضافة:

- `js/modules/ai-knowledge-pack.js` لحزمة معرفة عامة منظمة.
- `js/modules/ai-retrieval.js` لاختيار المقاطع الأكثر صلة فقط.
- `js/modules/ai-answer-engine.js` لتوليد الرد المحلي وبناء payload آمن للخادم.
- اقتراحات أسئلة 2.0 بعشر فئات: تأمين، المباراة، الرادار والتكتيك، الإصابات، الحماية، الكتابة، تطوير الموقع، الرياضة، الدراسة، التقنية.
- شارات مصدر الرد، النية المكتشفة، مواضيع السؤال، وأسئلة متابعة.
- ذاكرة جلسة محلية مختصرة بدون تخزين أسرار أو مفاتيح.

## Security Center Simplification

تم اختصار مركز الحماية والأمان ليصبح لوحة متابعة مباشرة تشمل:

- Hero مختصر.
- بطاقات حالة.
- تنبيه رسمي قصير.
- ماذا نحمي داخل تأمين.
- Cookies والخصوصية.
- حماية المساعد الذكي.
- الإبلاغ عن مشكلة أمنية.
- وضع الطوارئ.

## Backend Prompt Recommendation

إذا تم تحديث Backend الخاص بالمساعد، يفضل أن يلتزم بالرسالة التالية:

```text
أنت مساعد تأمين الذكي. أجب بالعربية الواضحة وبنبرة مفيدة ومختصرة.
- إذا كان السؤال عن منصة تأمين، استخدم siteKnowledge فقط ولا تخترع مباريات أو إصابات أو روابط.
- إذا كانت المعلومة غير موجودة في بيانات الموقع، قل: المعلومة غير متوفرة في بيانات الموقع الحالية.
- إذا كان السؤال عاما، افصل بوضوح بين المعرفة العامة وبيانات تأمين الرسمية.
- لا تقدم خطوات اختراق أو سرقة أو تجاوز أو جمع أسرار. قدم بدائل دفاعية آمنة.
- لا تشخص الإصابات ولا تصف أدوية. معلومات الإصابات في تأمين تنظيمية فقط.
- عند السؤال المركب، قسم الإجابة بعناوين قصيرة.
- استخدم generalKnowledge المسترجعة فقط كمقاطع مساعدة، ولا تفترض أن حزمة المعرفة كلها مرسلة لك.
```

## Verification Notes

- لا يتم إرسال حزمة المعرفة كاملة إلى الخادم.
- يتم إرسال المقاطع المسترجعة فقط داخل `generalKnowledge`.
- الأسئلة الحساسة أو الطبية الحساسة تبقى محلية لضمان الرد الآمن.
- Service Worker تم تحديثه للكاش الجديد وعدم تخزين ردود API أو الردود الفاشلة.
