# دليل تعديل صفحة الإصابات والحالات

هذا الملف يشرح كيف تضيف أو تعدل حالات الإصابات في موقع تأمين 2026 بدون لمس ملفات التصميم أو المنطق.

الملف المسؤول عن الحالات هو:

```txt
data/injuries-data.js
```

## شكل الحالة

انسخ هذا المثال داخل مصفوفة `injuryCases` وعدّل البيانات:

```js
{
  id: 'INJ-005',
  player: 'اسم اللاعب',
  caseName: 'اسم الإصابة أو الحالة',
  type: 'التواء',
  icon: 'fa-person-running',
  bodyPart: 'الكاحل',
  severity: 'medium',
  riskPercent: 45,
  status: 'تحت المتابعة',
  startDate: '2026-06-16',
  expectedReturn: '2026-06-25',
  effect: 'شرح مختصر لتأثير الحالة على اللعب.',
  description: 'شرح بسيط عن الحالة بلغة مفهومة.',
  care: [
    'راحة نسبية',
    'تخفيف الجهد',
    'متابعة الحالة بعد اللعب'
  ],
  history: [
    { date: '2026-06-16', title: 'تسجيل الحالة', text: 'شرح ما حدث أو آخر تحديث.' }
  ]
}
```

## درجات الخطورة

استخدم واحدة من القيم التالية في `severity`:

```txt
low       = خفيفة
medium    = متوسطة
high      = عالية
illness   = مرض أو تعب
recovery  = تعافي
```

كل قيمة لها لون وشكل مختلف في الموقع.

## نسبة الخطورة

ضع رقمًا من 0 إلى 100 في:

```js
riskPercent: 45
```

اقتراح بسيط:

```txt
0 - 30   حالة خفيفة
31 - 60  تحتاج حذر ومتابعة
61 - 85  عالية، يفضل تقليل اللعب
86 - 100 لا يفضل اللعب بدون رأي مختص
```

## الأيقونات المقترحة

الموقع يستخدم Font Awesome. أمثلة جاهزة:

```txt
fa-bone                 عظم / كسر
fa-person-running       التواء / ركض
fa-dumbbell             عضلة / إجهاد
fa-bandage              إصابة عامة
fa-head-side-cough      مرض / برد
fa-temperature-high     حرارة
fa-heart-pulse          حالة عالية الخطورة
fa-hand-holding-medical علاج / تعافي
fa-battery-quarter      تعب / إرهاق
```

## السجل المخفي

داخل `history` أضف تحديثات الحالة. هذا السجل لا يظهر مباشرة، بل يظهر عندما يفتح المستخدم تفاصيل الحالة.

مثال:

```js
history: [
  { date: '2026-06-16', title: 'ظهور الألم', text: 'ألم بعد احتكاك قوي.' },
  { date: '2026-06-18', title: 'تحسن', text: 'الألم أخف والحركة أفضل.' }
]
```

## ملاحظة مهمة

هذه الصفحة للتنظيم والمتابعة فقط، وليست تشخيصًا طبيًا. إذا كان هناك ألم شديد، تورم واضح، دوخة، حرارة عالية، أو صعوبة حركة، يجب سؤال شخص بالغ أو مختص.
