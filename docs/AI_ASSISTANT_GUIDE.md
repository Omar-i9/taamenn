# Taamen 2026 - AI Assistant Guide

## الفكرة

صفحة `المساعد الذكي` هي صفحة مستقلة داخل الموقع تقرأ بيانات تأمين 2026 فقط وتعرض إجابات محلية مفيدة عن:

- المباراة القادمة.
- آخر مباراة وملخص الأرشيف.
- الإصابات الحالية والحالات المتعافية.
- صفحات الموقع وحالة الإصدار.
- رسالة واتساب جاهزة من بيانات المباراة القادمة.

المساعد لا يعدل ملفات البيانات، ولا يكتب داخل `data/site-data.js` أو `data/injuries-data.js`.

## الوضع الحالي

التنفيذ الحالي يعمل بدون Backend:

```txt
Frontend
-> buildSiteKnowledge()
-> local fallback answer
-> chat UI
```

إذا كان `AI_ENDPOINT` فارغًا داخل `js/modules/api-client.js`، يعمل المساعد محليًا من بيانات الموقع ولا يحاول الاتصال بأي خدمة خارجية.

## الربط لاحقًا

عند إضافة Backend لاحقًا، غيّر `AI_ENDPOINT` ليشير إلى endpoint خارجي آمن:

```js
export const AI_ENDPOINT = 'https://your-backend.example.com/api/ai';
```

الواجهة سترسل:

```json
{
  "question": "سؤال المستخدم",
  "knowledge": "ملخص بيانات الموقع"
}
```

ويجب أن يعيد Backend:

```json
{
  "answer": "نص الرد"
}
```

## الأمان

- لا يوجد API key داخل الواجهة.
- لا يوجد اتصال مباشر من المتصفح إلى OpenAI.
- لا يتم تخزين أي مفتاح داخل `localStorage`.
- أي استخدام مستقبلي لـ OpenAI يجب أن يتم من Backend فقط.

## حدود المساعد

- المساعد يقرأ ولا يحرر.
- معلومات الإصابات تنظيمية فقط وليست تشخيصًا طبيًا.
- إذا لم يكن Backend متاحًا، يظهر fallback محلي بدل كسر الصفحة.
- زر المشاركة يعتمد على `Web Share API` عند توفرها، وإلا ينسخ الرد.

## ملفات الميزة

- `index.html`: صفحة AI، زر التنقل، زر AI العائم.
- `js/modules/ai-assistant.js`: بناء المعرفة والردود المحلية وواجهة المحادثة.
- `js/modules/api-client.js`: endpoint مستقبلي آمن بدون مفتاح.
- `css/23-ai-assistant.css`: تصميم صفحة المساعد والزر العائم.
- `sw.js`: كاش ملفات المساعد بعد التأكد من وجودها.
