# Taamen 2026 — V3.5 Recovery & Tactical Fix

## ما الجديد؟

- تحديث نظام الإصابات ليقسم الحالات تلقائيًا إلى حالات نشطة وسجل تعافي سابق.
- إضافة حالة عمر الحالية: التواء الكاحل الأيمن مع انتفاخ عند الرمانة.
- نقل إصابة سكافي بالدراجة إلى سجل الإصابات السابقة لأنها بدأت تقريبًا في شهر 3 وانتهت قبل فترة.
- إضافة شريط مرحلة الحالة: من الإصابة إلى الرجوع أو التعافي.
- تحسين ظهور التعافي بصريًا من خلال شارة "تعافى" وتأثير لوني خاص.
- إصلاح فتح خطة المتابعة وسجل الحالة داخل كروت الإصابات.
- تحسين الرادار التكتيكي: السحب، اللمس، الضغط المزدوج، تحديد الرتب، وتفعيل زر ضغط Y.
- تحسين عمل أزرار الصفحة الرئيسية والتأكد من أن أزرار الانتقال لها أولوية نقر واضحة.
- إضافة ملف CSS مستقل للإصلاحات الجديدة: `css/17-recovery-tactical-fix.css`.

## تعديل الإصابات

عدّل الحالات من الملف:

```txt
data/injuries-data.js
```

الحالة تعتبر متعافية وتنتقل تلقائيًا للسجل السابق إذا:

- كانت `severity: 'healed'`
- أو كان `status` يحتوي على كلمة `تعافى`
- أو كان `recoveryDate` قد مضى
- أو انتهى `expectedReturn` وكانت الخطورة منخفضة جدًا

## ملاحظة صحية

الموقع لتنظيم جاهزية اللاعبين فقط، وليس تشخيصًا طبيًا. الجروح المفتوحة أو النزيف أو التورم القوي أو صعوبة المشي تحتاج متابعة من الأهل أو مختص.
