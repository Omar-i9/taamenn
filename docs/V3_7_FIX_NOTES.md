# V3.7 — Radar & Injury Final Fix

هذا التحديث صيانة مركزة على صفحتين:

1. صفحة الرادار التكتيكي.
2. صفحة الإصابات والحالات.

## إصلاحات الرادار

- تقوية أزرار حفظ، إغلاق، ومسح داخل نافذة تعديل اللاعب.
- إضافة معالجة مباشرة للأزرار حتى لا تتعطل بسبب طبقات CSS أو أحداث أخرى.
- تحسين حفظ الاسم، دور الفريق، التعليمات، والكابتن.
- منع تضارب الكابتن داخل نفس الفريق.
- تحسين الضغط والسحب على الجوال والكمبيوتر.
- تحسين ظهور الرتب والتعليمات فوق اللاعب.

## إصلاحات الإصابات

- حذف أي بطاقة أو نص تعديل ملفات من واجهة المستخدم.
- إبقاء شرح التعديل داخل ملفات docs فقط.
- فصل الحالات النشطة عن الحالات السابقة بفاصل واضح.
- تحويل الحالات المتعافية إلى سجل مخفي واحد.
- السجل السابق يظهر كشريط طويل مشابه لتجميعات الملفات، ويفتح بضغطة واحدة.
- داخل السجل تظهر الملفات كعناصر عادية، ليست أزرارًا منفصلة.
- إصابة سكافي محفوظة داخل سجل المتعافين.
- إصابة عمر الحالية تبقى ضمن الحالات النشطة حتى موعد الرجوع أو التعافي.
- زر خطة العلاج وسجل الحالة يعمل بدون القفز لأول الصفحة.

## طريقة الأرشفة التلقائية

الحالة تنتقل تلقائيًا إلى سجل الإصابات السابقة إذا تحقق أحد الشروط:

- `severity: 'healed'`
- `severity: 'recovery'`
- status يحتوي على كلمة `تعافى`
- `recoveryDate` انتهى
- `expectedReturn` أصبح تاريخًا سابقًا
