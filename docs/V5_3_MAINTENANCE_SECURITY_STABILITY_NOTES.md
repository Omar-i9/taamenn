# Maintenance pass: Security Center stability and cookie controls

تم تنفيذ مراجعة صيانة لملفات الموقع، فحص ملفات JavaScript، تثبيت رابط مركز الحماية والأمان داخل الشريط الرئيسي، وتحسين استقرار نظام الكوكيز وتفضيلات الخصوصية.

## ملخص الصيانة

- نقل رابط `الحماية والأمان` إلى شريط التنقل الرئيسي بدل قائمة المزيد.
- تثبيت الرابط نفسه داخل المجموعة الرئيسية في قائمة الهاتف.
- مراجعة ربط صفحة `#security` مع الراوتر وحالة الرابط النشط.
- مراجعة نظام موافقة الكوكيز ومنع تكرار البانر أو لوحة الإعدادات.
- تأكيد أن التحليلات تبقى غير مفعلة افتراضيًا.
- تحديث قائمة التخزين المؤقت في Service Worker للإصدار الجديد.
