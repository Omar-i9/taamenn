# Taamen 2026 — V3.8 Radar Pro

هذا الإصدار مخصص لإصلاح وتحسين صفحة الرادار فقط.

## ما تغير؟

- إعادة بناء منطق السحب والتحريك داخل الملعب.
- منع بقاء بيانات قديمة معطوبة عبر ترميم تخزين اللاعبين تلقائيًا.
- تحسين ضغط اللاعب على الجوال والكمبيوتر.
- تحسين نافذة تعديل اللاعب وحفظ الاسم والدور والتعليمات.
- إضافة لوحات جانبية للفريقين تعرض الأدوار، الكابتن، والتعليمات.
- إضافة قائمة أسماء سريعة لاختيار أسماء اللاعبين بسرعة.
- تحسين شكل الملعب، الخطوط، الدائرة، المناطق، واللمسات الحركية.
- إضافة تكتيك جديد: مرتدة 2-1-1.

## طريقة تعديل اللاعبين الافتراضيين

افتح الملف:

```txt
data/site-data.js
```

وعدّل مصفوفة:

```js
export const defaultPlayers = [...]
```

كل لاعب يحتوي على:

- `id`: رقم ثابت لا تغيره إلا عند الضرورة.
- `team`: إما `home` أو `away`.
- `name`: اسم اللاعب.
- `x`, `y`: مكان اللاعب على الملعب بالنسبة المئوية.
- `teamRole`: دور اللاعب مثل كابتن أو صانع ألعاب.
- `instruction`: تعليمات تظهر فوق اللاعب.
- `captain`: true أو false.

## قائمة الأسماء السريعة

تعدل من:

```js
export const playerPool = [...]
```

هذه القائمة لا تضيف لاعبين جدد للملعب، لكنها تسهل اختيار الاسم من نافذة تعديل اللاعب أو اللوحات الجانبية.
